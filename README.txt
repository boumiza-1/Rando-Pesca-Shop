METTRE SUR GITHUB PAGES
1. Décompressez le ZIP sur votre ordinateur.
2. Créez un dépôt GitHub PUBLIC (ex : rando-pesca-shop).
3. Dans le dépôt, cliquez « Add file » > « Upload files ».
4. Sélectionnez TOUS les fichiers du dossier extrait (pas le ZIP).
5. Cliquez « Commit changes ».
6. Settings > Pages > Build and deployment > Deploy from a branch.
7. Choisissez « main » et « / (root) », puis « Save ».
8. Attendez la publication. Votre lien sera généralement :
   https://VOTRE-UTILISATEUR.github.io/rando-pesca-shop/

IMPORTANT : index.html doit être DIRECTEMENT à la racine du dépôt.
Pour tester en local, ouvrez index.html avec votre navigateur.
La fonction "Partager" utilisera le lien de la page ouverte ;
après publication GitHub, elle partagera automatiquement votre lien GitHub Pages.

Aucun catalogue ni fonction e-commerce : c'est une carte de visite mobile
avec les boutons utiles, la photo du magasin et son identité visuelle.
